# Самостоятельная практическая работа  
## Web Scanning средствами Kali Linux

### Цель работы

Провести самостоятельную разведку и базовое сканирование учебного веб-приложения с использованием инструментов Kali Linux.

Учебный ресурс:

```text
https://demo.testfire.net
```

Используемые инструменты:

```text
curl
httpx-toolkit
WhatWeb
ffuf
Nuclei
```

> Работать только с указанным учебным ресурсом. Для `ffuf` и `Nuclei` использовать ограничение не более **5 запросов в секунду**.

---

Проверьте доступность сайта средствами `curl`.

- HTTP status code;
- тип содержимого;
- веб-сервер, если он указан;
- минимум 3 HTTP-заголовка.

В отчёте:

```text
Команда:
Результат:

```

Добавьте скриншот.
