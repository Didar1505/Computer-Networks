# Практическая работа  
## Исследование и настройка сети Windows

### Цель работы

Развернуть небольшой сетевой сегмент, настроить сетевые службы, проверить их доступность, ограничить доступ к отдельным сервисам и исследовать сетевой трафик.

Используемые инструменты:

- `ipconfig`
- `arp`
- `nmap`
- `netstat`
- PowerShell
- `curl`
- `Test-NetConnection`
- Windows Firewall
- Wireshark
- Python HTTP Server

# Задание 1. Исследование локальной сети

Определите параметры своего компьютера:

```powershell
ipconfig /all
```

Найдите:

- IPv4-адрес;
- маску подсети;
- шлюз по умолчанию;
- DNS-сервер;
- MAC-адрес.

Определите адрес своей сети.

После этого найдите активные устройства:

```powershell
nmap -sn <адрес_сети>
```

Просмотрите ARP-таблицу:

```powershell
arp -a
```

Составьте небольшую карту найденных устройств:

```text
IP-адрес
MAC-адрес
предполагаемое назначение устройства
```

# Задание 5. Найдите процесс, открывший порт

На сервере найдите процесс, который слушает порт `8080`.

```powershell
netstat -ano | findstr :8080
```

Определите PID.

После этого найдите программу:

```powershell
tasklist | findstr <PID>
```

Дополнительно выполните через PowerShell:

```powershell
Get-NetTCPConnection -LocalPort 8080
```

```powershell
Get-Process -Id <PID>
```

Установите связь:

```text
порт → PID → процесс
```

# Задание 7. Ограничение доступа через Windows Firewall

HTTP-сервис на порту `8080` должен быть доступен всем компьютерам вашей лабораторной сети.

Создайте правило:

```powershell
New-NetFirewallRule `
  -DisplayName "HTTP LAB" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 8080 `
  -Action Allow
```

Теперь настройте доступ к SMB так, чтобы порт `445` был доступен только одному выбранному компьютеру.

Пример:

```powershell
New-NetFirewallRule `
  -DisplayName "SMB LAB" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 445 `
  -RemoteAddress <IP-разрешенного-компьютера> `
  -Action Allow
```

Проверьте результат с двух разных компьютеров:

```powershell
Test-NetConnection <IP-сервера> -Port 445
```

Сравните результаты.

# Итоговое задание

Разверните внутренний сервер организации со следующими требованиями:

```text
HTTP:
TCP 8080
должен быть доступен всем компьютерам лабораторной сети.

SMB:
TCP 445
должен быть доступен только одному выбранному компьютеру.

Другие компьютеры не должны иметь доступа к SMB.
```

Необходимо самостоятельно:

1. определить IP-адрес сервера;
2. запустить HTTP-службу;
3. создать сетевой файловый ресурс;
4. проверить открытые порты;
5. определить процессы, использующие эти порты;
6. настроить Windows Firewall;
7. проверить доступ с разных компьютеров;
8. получить HTTP-файл через `curl`;
9. подтвердить ограничения через Nmap и `Test-NetConnection`;
10. показать HTTP-запрос и TCP-соединение в Wireshark.

## Работа считается выполненной, если вы можете показать:

```text
HTTP работает с другого компьютера.

SMB работает только для разрешённого компьютера.

Ограниченный компьютер не имеет доступа к SMB.

Nmap подтверждает состояние портов.

Процессы, использующие порты, определены.

HTTP-запрос найден в Wireshark.

TCP handshake найден в Wireshark.
```
