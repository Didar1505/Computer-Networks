## Базовые сетевые утилиты Kali Linux

> Все задания выполняются только в собственной локальной сети, виртуальной лаборатории или на разрешённых учебных ресурсах.

---

## Задание 1. Определение сетевых интерфейсов

Выполните:

```bash
ip addr
```

Определите:

- имя активного сетевого интерфейса;
- IPv4-адрес;
- IPv6-адрес, если имеется;
- маску подсети;
- MAC-адрес интерфейса;
- состояние интерфейса.

Запишите полученные данные.

---

## Задание 2. Краткое определение IP-адреса

Выполните:

```bash
hostname -I
```

Сравните полученный адрес с результатом:

```bash
ip addr
```

Определите, какой адрес относится к активному сетевому интерфейсу.

---

## Задание 3. Исследование таблицы маршрутизации

Выполните:

```bash
ip route
```

Определите:

- маршрут по умолчанию;
- IP-адрес шлюза;
- сетевой интерфейс;
- адрес локальной сети.

Дополнительно выполните:

```bash
ip route get 8.8.8.8
```

Определите, через какой шлюз и интерфейс будет отправлен пакет.

---

## Задание 4. Проверка связи со шлюзом

Найдите адрес шлюза через:

```bash
ip route
```

Проверьте его доступность:

```bash
ping -c 4 IP_ШЛЮЗА
```

Определите:

- количество отправленных пакетов;
- количество полученных пакетов;
- процент потерь;
- среднее время ответа.

---
